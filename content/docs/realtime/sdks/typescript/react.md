Import the React bindings from `@neon/realtime-react`. They run in your React frontend: [`RealtimeProvider`](#react-realtimeprovider) shares one client, [`useLiveQuery`](#react-uselivequery) subscribes a component to a sealed query, and [`useRealtimeClient`](#react-userealtimeclient) returns the shared client. They're taught in the [React section](/docs/realtime/guides/reactivity#react) of the reactivity guide.
