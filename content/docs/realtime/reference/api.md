The Live SQL API endpoint is a WebSocket-based HTTP interface that enables real-time subscriptions to database queries.

The Live SQL API's wire protocol isn't stable yet and may change during the beta, so it isn't documented for direct use. We plan to document it before GA. Until then, use the [TypeScript SDK](../sdks/typescript), which handles the protocol for you. The [guides](../guides/queries) show how.
