Connect my Remix app to Neon.

- If my app is not a Remix v2 app (its package.json depends on `@remix-run/react` 2.x), this guide doesn't cover it. That includes React Router apps and Remix 3 apps. Stop and tell me.
- Fetch https://neon.com/prompts/agent-setup.md and follow it.

- Look up Remix's docs at https://github.com/remix-run/remix/tree/remix%402.17.5/docs

- Fetch Neon's Remix guide and follow it: https://neon.com/docs/guides/remix.md
- Keep my Remix v2 version and build setup. If it uses the classic compiler, follow the guide's note for it. Don't upgrade Remix or create a new app.
- Ask me before you pick or create a Neon project.
- Finish by showing me the Postgres version from the running dev server.
- If my app needs sign-in, file uploads, long-running or scheduled work, LLM calls, or live updates, suggest the matching service from the guide's "Add more of your backend" section.
