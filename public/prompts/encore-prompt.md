Connect my Encore app to Neon.

- Fetch https://neon.com/prompts/agent-setup.md and follow it.

- Look up Encore's docs at https://encore.dev/llms.txt and its agent skills at https://github.com/encoredev/skills

- Fetch Neon's Encore guide and follow it: https://neon.com/docs/guides/encore.md
- This guide is for Encore.ts. If my app is written in Go, ask me before you continue.
- Ask me before you pick or create a Neon project.
- Ask me before you sign in to Encore, deploy (which includes `git push encore`), or create an Encore environment.
- Ask me to add a Neon API key in the Encore Cloud dashboard (App Settings > Integrations > Neon). Don't ask me for the key, and don't print it.
- Finish by showing me the Postgres version from the running server. Use the deployed Neon-backed environment or the self-hosted image, not `encore run`, which uses Encore's local Postgres.
