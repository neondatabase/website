Help me get set up with Neon's managed Better Auth, based on my project:

1. Install the Neon CLI with `npm install -g neon@latest`.
2. Read Neon's skill at https://neon.com/.well-known/agent-skills/neon/SKILL.md and use it to guide this setup.
3. Run `neon init` to link a project with Neon's managed Better Auth enabled and install Neon's agent tooling.
4. Add simple email-and-password sign-up to this project using Neon's Auth SDK, then prove it works: sign up a real test user and read the current user back. Don't print secrets.
